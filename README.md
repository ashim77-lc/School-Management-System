# School Management System 🏫

A full-stack School Management System built with Python Flask, SQLite and Bootstrap.

## 🌐 Live Demo
Previously deployed. Now replaced by Restaurant Management System.
Live site: [ashimdev.pythonanywhere.com](https://ashimdev.pythonanywhere.com/)

## ✨ Features
- Add students with up to 6 subjects
- Auto GPA and Grade calculation
- Edit and delete students
- Search by name
- Responsive Bootstrap UI

## 🛠 Tech Stack
- Python + Flask
- SQLite Database
- Bootstrap 5
- Jinja2 Templates

## ▶ How to Run
1. Install Flask: `pip install flask`
2. Run database setup: `python database.py`
3. Start server: `python app.py`
4. Visit: `http://127.0.0.1:5000`
